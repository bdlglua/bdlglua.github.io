# BDLXS Fiverr Template

Responsive HTML/CSS/JavaScript template.

## Files
- `index.html`
- `style.css`
- `script.js`

## GitHub Pages
Upload the folder contents to a public GitHub repository, then enable Pages from:
Settings → Pages → Deploy from a branch → main → /(root)

## Customization
Replace text, colors, email address and sections with your own content.
